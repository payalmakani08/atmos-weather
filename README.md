
# ATMOS Weather

ATMOS Weather is a responsive weather website built using HTML, CSS and JavaScript.

## Features

- Search weather by city name
- Current temperature and weather conditions
- Feels-like temperature, humidity, wind speed and visibility
- Sunrise, sunset and UV index
- Air-quality information when available
- Hourly and seven-day forecasts
- Daily high and low temperature chart
- Save and remove favorite cities
- Celsius and Fahrenheit settings
- Light and dark themes
- Optional location access
- Responsive layout for mobile and desktop

## Technologies

- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo Weather API
- Open-Meteo Geocoding API
- Open-Meteo Air Quality API
- GitHub Pages

## Run the project

Open `index.html` through a local web server or visit the published GitHub Pages website.

Weather data requires an internet connection. Location access requires browser permission.
