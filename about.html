About Atmos.

A modern weather visualization experience.

🌤️ What is Atmos?


Atmos is a responsive weather application designed to make weather information beautiful, interactive and easy to understand.


Search any city to view current weather conditions, temperature trends, air quality, sunrise, sunset, UV index and more.


Atmos uses the JavaScript Fetch API to retrieve real-time weather data.


The interface is designed to work on phones, tablets and computers.


🚀 Technologies


HTML • CSS • JavaScript • Fetch API • Three.js • Chart.js
